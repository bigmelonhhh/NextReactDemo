# NextReactDemo

基于 Next.js 16、React 19、TypeScript、Tailwind CSS v4 与 shadcn/ui 搭建的前端项目基线，并实现智医康官网首页。

## 技术栈

- Next.js App Router
- React 19
- TypeScript
- Tailwind CSS v4
- shadcn/ui、Base UI、lucide-react

## 本地运行

```bash
npm install
npm run dev
```

## 验证

```bash
npm test
npm run lint
npm run build
```
